Local-first privacy

✓Timeline data is stored locally with SwiftData.
✓No Memory Trail account is required.
✓Pause capture or exclude apps at any time.
✓Passwords and Wallet are excluded by default.
✓Ask Memory Trail searches local history.

Accessibility setup

Detailed activity context uses macOS Accessibility. If Memory Trail does not appear automatically, open System Settings → Privacy & Security → Accessibility, click +, choose Memory Trail from Applications, enable it, and relaunch if macOS asks.
