# Memory Trail Changelog

## 1.0 (Build 1)

Current macOS production release.

- Privacy-first local activity timeline with local SwiftData storage.
- Live timeline, Ask Memory Trail search, favorites, and manual memories.
- Browser, email, Teams, file/document, and optional clipboard context capture.
- Pause controls, app/process exclusions, and default protection for Passwords and Wallet.
- No cloud timeline sync, external data connectors, analytics SDK, advertising SDK, or remote Memory Trail account.
- Captured timeline data is not transmitted to an external service.
- No AI-generated timeline summaries.
- Refined onboarding and Settings privacy UI, including consistent shield/lock iconography.
- About Memory Trail now links directly to the GitHub project page.
- Release packaging standardized as `MemoryTrail-1.0.dmg`.
